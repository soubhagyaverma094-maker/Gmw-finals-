One-click Publish (advanced)
Easiest way to go live: close this and use ⬇️ Download → upload the folder to vercel.com. No setup needed.

This screen is only for automatic one-click publishing, which needs a backend step first.
Setup once: (1) deploy the api/deploy.js file to a Vercel project, (2) add your token there as an env var, (3) paste that project's deploy URL below.
The endpoint must be a full https URL ending in /api/deploy — NOT an email or the token. If you haven't deployed api/deploy.js yet, leave this blank and use ⬇️ Download instead.
